Generated by `npm run docs` (`scripts/gen_api_docs.mjs`) from the runtime objects and the JSDoc comments in `src`; do not edit by hand. Names and arguments follow PyPSA: Python keyword arguments are a trailing options object.

### `n.to_crs(newCrs)`

Transform the shape geometries and bus coordinates to another CRS (EPSG
code or "EPSG:<code>"; supported: 4326, 4258, 3857, 3035, 32632, 32633,
25832, 25833). Like PyPSA, shapes are transformed in x/y order while the
bus coordinates go through `Transformer.from_crs(current, new)` without
`always_xy`, i.e. in each CRS's axis order (latitude first for
geographic CRS), which swaps them; see NEXT_STEPS.

## Optimisation (`n.optimize`)

`await n.optimize(opts)` builds and solves the model; the methods below are attached to `n.optimize`.

### `n.optimize.add_load_shedding({ suffix = " load shedding", buses = null, sign = 1e-3, marginal_cost = 1e2, p_nom = 1e9 } = {})`

Add expensive load-shedding generators at all (or the given) buses.

### `n.optimize.assign_duals(assignAllDuals = false)`

Write the duals of the model constraints (marginal prices, `mu_*`) to the component data.

### `n.optimize.assign_solution()`

Write the primal solution of `n.model` to the component data (`p`, `p_nom_opt`, ...).

### `n.optimize.build_linexpr_from_weights(weights, model = null)`

Linear expression `sum(weights * variables)` for {component: {attr: coeffs}}.

### `n.optimize.create_model(opts = {})`

Build the optimisation model (`n.model`) without solving it; same options as `optimize`.

### `n.optimize.fix_optimal_capacities()`

Fix the capacities of extendable assets to their optimised values (no longer extendable).

### `n.optimize.fix_optimal_dispatch()`

Set the dispatch setpoints (`p_set`) to the optimised dispatch.

### `n.optimize.optimize(opts = {})`

Build the linopy model, solve it with HiGHS and assign the results (`await n.optimize(opts)`): `snapshots`, `multi_investment_periods`, `transmission_losses`, `linearized_unit_commitment`, `solver_options`, `extra_functionality`, ...

### `n.optimize.optimize_and_run_non_linear_powerflow(opts = {})`

Optimise, then fix the dispatch and run a non-linear power flow.
@returns {Promise<object>} status, termination_condition and pf results

### `n.optimize.optimize_mga(opts = {})`

Optimise along `weights` within `slack` of the optimal system cost.

### `n.optimize.optimize_mga_in_direction(opts = {})`

Optimise in a direction of the space spanned by `dimensions`.

### `n.optimize.optimize_mga_in_multiple_directions(opts = {})`

Optimise in several directions (sequentially, each on a copy of the
network). Returns [directions, coordinates] DataFrames of the successful runs.

### `n.optimize.optimize_security_constrained(opts = {})`

Security-constrained optimisation: branch flows after any of the given
branch outages (linearised via BODF) must respect the branch limits.
@param {object} [opts]
@param {Array} [opts.branch_outages] names of lines or [component, name] pairs

### `n.optimize.optimize_transmission_expansion_iteratively(opts = {})`

Iterative linear optimisation updating line impedances according to the
expanded capacities (Hagspiel et al.), followed by a final run with fixed
(optionally discretised) branch capacities.

### `n.optimize.optimize_with_rolling_horizon(opts = {})`

Optimise in windows of `horizon` snapshots overlapping by `overlap`,
carrying storage levels from one window to the next.

### `n.optimize.post_processing()`

Derive results after a solve: branch flows at all ports, bus injections, voltage angles.

### `n.optimize.project_solved(dimensions)`

Evaluate solved dimensions {key: weights} as a Series.

### `n.optimize.solve_model({ extra_functionality = null, solver_name = "highs", solver_options = {}, log_to_console = false, assign_all_duals = false, reformulate_sos = false } = {})`

Solve the existing model (`n.model`) and assign the results.
